# Version history, safer saving, and comment threads

## Version history

- Solo writes keep earlier copies as you work. Document menu, Version history.
- Download or restore any copy. A restore can be undone.

## Saving

- "Saved" means stored. If a save fails, the page stays "Unsaved" and keeps trying.
- Typing during a save is kept.
- A story changed in another tab pauses saving and asks you first.
- The Save button greys out when there is nothing to save.
- Deleting a chapter asks first.

## Comments

- Reply to a reply.
- Emoji reactions on comments and replies.
- Reply, Edit, Add reaction and Delete live under the ⋯ on each message.
- Hover a name to see author or beta reader.
- An amber ! marks a comment whose words have changed. Hover it for details.
- A reader's note is never lost to the author's save.
